# Changelog

## 1.0.0

- Extracted a reusable UniTask scene service from the project's SceneService.
- Added scene asset references and Editor GUID/path synchronization.
- Added single/additive loading, optional activation, and guarded unload.
- Added transition concurrency protection, cancellation semantics, and screen cleanup.
- Added optional VContainer and Event Bus integrations.
- Added DOTween screen and VContainer bootstrap samples.
- Removed fixed wait, forced garbage collection, and stacked progress tweens.
- Added transition tests, installation instructions, migration guide, and release checklist.
